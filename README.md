# Граником — версия для публикации

Эта папка содержит готовый статический сайт. Её можно отправить в отдельный **публичный** репозиторий GitHub и бесплатно разместить через GitHub Pages. `index.html` уже лежит в корне. Сборка на GitHub не требуется.

## Как опубликовать

1. Добавьте эту папку как локальный репозиторий в GitHub Desktop и опубликуйте его как **Public**. Исходные прайсы, архивы и рабочие скрипты из родительской папки в этот репозиторий не входят.
2. Откройте репозиторий на GitHub: **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку **main** и папку **/(root)**. Сохраните.
4. После публикации адрес появится в разделе Pages. Для обычного репозитория он будет вида `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

Сайт использует только относительные ссылки, поэтому работает и на адресе GitHub Pages с именем репозитория в пути. Файл `.nojekyll` оставляет файлы сайта без обработки Jekyll.

## Как обновлять сайт

Рабочие файлы находятся **в родительской папке проекта**, а эта папка пересоздаётся из них. После изменения каталога или оформления выполните в родительской папке:

```powershell
& 'C:\Users\Dmitriy\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' prepare_github_pages.py
```

Скрипт проверит каталог, обновит страницы и скопирует только изображения, которые реально используются. Затем зафиксируйте изменения этого репозитория и отправьте их на GitHub. Файлы `.git`, `README.md` и `.gitignore` сохраняются при повторной сборке.

## Свой домен

Когда будет куплен домен, его можно добавить в **Settings → Pages → Custom domain**, а затем настроить DNS у регистратора по подсказкам GitHub. Пока домен неизвестен, файл `CNAME` намеренно не добавлен. Бесплатный адрес GitHub Pages работает и без собственного домена.

## Локальная проверка

Открывайте сайт через локальный сервер, иначе браузер может заблокировать загрузку каталога:

```powershell
& 'C:\Users\Dmitriy\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' -m http.server 8766 --bind 127.0.0.1 --directory github-pages
```

Затем откройте `http://127.0.0.1:8766/`.
